    About and privacy

    ScheduGen 0.18.0 (data schema v4)

    ScheduGen builds a first draft of the daily position schedule. It is a single page that runs entirely inside this browser tab.

    What it does and does not do

    • It makes no network requests. Nothing you type, paste or generate is sent anywhere. The page carries a rule (a Content Security Policy) that makes the browser itself refuse any connection.
    • It keeps its data only in this browser's local storage on this computer, under the names listed below. It uses no cookies.
    • A file leaves the page only when you press a button: the schedule as an Excel file (.xlsx) and the backup (.json). A file enters only when you choose a backup file, open a day file, choose a schedule workbook (.xlsx), or paste text.
    • It contains no third-party program code. The icons are Font Awesome Free (CC BY 4.0), drawn inline.

    What is stored in this browser

    Browser storage can be cleared by the browser or by IT policy. The backup file is the copy you control.
